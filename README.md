# LiveKit AI Voice Avatar Agent

Real-time AI voice avatar built with Python.

## Stack

- LiveKit Agents
- Google Gemini Live API
- Tavus Avatar
- Python
- python-dotenv

## How it works

User Voice
↓
LiveKit
↓
Gemini Live
↓
AI Response
↓
Tavus Avatar
↓
Real-time Voice + Avatar

## Run

`powershell
python agent_worker.py dev
